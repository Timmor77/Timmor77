## Selected work

- **[Signs](https://github.com/Timmor77/Signs)**: French Sign Language alphabet trainer that runs
  entirely in the browser (MediaPipe + 147 kB ONNX MLP, ~30 fps). Cross-signer study over
  7 protocols: **90.2% top-1 on unseen signers**. [Live demo](https://timmor77.github.io/Signs/)
- **[FractalFlow](https://github.com/Timmor77/FractalFlow)**: deep-zoom fractal renderer
  (perturbation theory + double-double, zoom ≈1e-28) in WGSL, GLSL and CUDA, pixel-identical to an
  mpmath reference; ≈922 GIter/s on an RTX 3060 Ti. [Live demo](https://timmor77.github.io/FractalFlow/)
- **[EV-Pulse](https://github.com/Timmor77/EV-Pulse)**: day-ahead EV charging-load forecasting
  (ACN-Data): baseline + LightGBM residual, **−29.8% MAE at Caltech, −14.7% across sites** on an
  untouched 60-day holdout. FastAPI, Streamlit, Docker, CI.
- **[Caraml](https://github.com/LucideAI/Caraml)**: web OCaml IDE with an OCaml interpreter written
  from scratch in TypeScript and a memory visualizer (stack, heap, environments).
